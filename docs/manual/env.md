# Переменные окружения

Приоритет — **флаг > переменная окружения / `.env` > встроенное умолчание**, и считается он
**для каждого значения отдельно**: `--token` в командной строке не отменяет endpoint, пришедший
из `.env`.

## Список

| Переменная | Что задаёт | Умолчание | Перебивается флагом |
| --- | --- | --- | --- |
| `PIXSO_REMOTE_MCP_URL` | адрес удалённого MCP (маршрут по ссылке) | `http://127.0.0.1:3667/remote-mcp` | `--endpoint <url>` |
| `PIXSO_LOCAL_MCP_URL` | адрес локального MCP (маршрут по guid) | `http://127.0.0.1:3667/local-mcp` | `--endpoint <url>` |
| `PIXSO_REMOTE_MCP_TOKEN` | токен удалённого маршрута | пусто | `--token <token>` |
| `FG_KITS_DIR` | корень корпусов вместо `~/.fg/kits` | `~/.fg/kits` | нет |
| `NO_COLOR` | любое непустое значение выключает цвет | не задана | нет |
| `FORCE_COLOR` | непустое значение (кроме `0` / `false`) включает цвет даже в пайпе; `0` / `false` выключает | не задана | нет |
| `COLORTERM` | `truecolor` / `24bit` разрешают 24-битную палитру | не задана | нет |

Три имени `PIXSO_*` зафиксированы владельцем и не переименовываются. Два URL-умолчания —
**заглушки** в коде; реальный адрес задают `--endpoint`, переменная окружения или правка
`cli/src/constants.ts`. Токен по умолчанию пуст: секрету не место в опубликованном бандле.

## `.env`

Файл `./.env` в текущем каталоге читается при старте автоматически; если его нет — обычное дело,
и никто об этом не пишет. Загружает встроенный `process.loadEnvFile`, без внешних зависимостей.

- **Реальное окружение сильнее файла**: переменная, уже стоящая в окружении, из `.env` не
  перетирается. Поэтому `.env` и окружение — одна ступень приоритета, а не две.
- **Разбор снисходительный**: строка без `=` или `=` без значения пропускается без ошибки.
- **Нечитаемый файл** (например, каталог с именем `.env`) — локализованное сообщение, а не стек:

```
не удалось загрузить …/.env: Contents of '…/.env' should be a valid string.
```

Минимальный `.env`:

```
PIXSO_REMOTE_MCP_TOKEN=<ваш токен>
```

Через `.env` проходит любая из переменных таблицы, не только `PIXSO_*`.

## Цвет и поток

`NO_COLOR` — выключатель **цвета**, а не терминала: живая строка с перерисовкой в настоящем
терминале остаётся, уходят только SGR-последовательности. Режим вывода — живая строка или
построчный журнал фаз — выбирается по TTY-ности потока, а не по цвету. Подробнее —
[ci.md](ci.md).

Пустая строка считается «не задано» для URL-переменных: `PIXSO_REMOTE_MCP_URL=` в `.env` — это
вычеркнутая строка, а не просьба сходить на пустой адрес.
