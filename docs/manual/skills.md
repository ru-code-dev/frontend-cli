# Навыки для CLI-агента

[`bash install`](setup.md) кладёт три навыка в `<папка CLI>/skills/` — ту папку CLI, которую
называет preflight ru-code (`CONFIG_DIR`, обычно `~/.qwen`). Загрузчик навыков qwen 0.21.1
читает их как навыки уровня пользователя — имена с двоеточием, описания по-русски.

| Папка                | Имя навыка           | Что делает                                                              |
| -------------------- | -------------------- | ----------------------------------------------------------------------- |
| `fg-get-pixso-specs` | `fg:get-pixso-specs` | `--pprompt <ссылка> -o <файл>` → читает Markdown-спецификацию кадра      |
| `fg-get-pixso-html`  | `fg:get-pixso-html`  | `--phtml <ссылка> -o <файл>` → читает HTML/CSS кадра (только нужные части) |
| `fg-project-report`  | `fg:project-report`  | спрашивает «текущий каталог / git-URL», `--preport … --format html,summary -o …`, отчитывается по `report.summary.json` |

Все три — по-русски, сценарий строгий: команды копируются дословно, у каждого шага маркер
успеха, при ошибке агент показывает последние строки вывода и останавливается.

## Команды внутри

В каждом навыке команда записана с **абсолютными путями**, известными на момент установки:

```bash
"<node>" "<корень ru-code>/fg/bin/fg.mjs" --pprompt "<ССЫЛКА>" -o "<ФАЙЛ>"
```

Первый шаг каждого навыка — проверка, что этот `fg.mjs` на месте. Если его нет (например, после
переезда корня ru-code, см. [setup.md](setup.md)), агент передаёт пользователю строку
`fguard не найден: …/fg.mjs. Установите его заново: склонируйте репозиторий релиза fguard и
выполните в нём bash install` и останавливается.

`<node>` — тот же node, что выбрал установщик ([setup.md](setup.md#node)), так что навыкам не
нужен `node` в `PATH` агента. Повторный `bash install` перезаписывает навыки с новыми путями.

Куда пишет отчёт `fg:project-report`:

- текущий каталог → `<проект>/fg-out/` (`report.html`, `report.summary.json`);
- git-URL → `<каталог запуска>/fg-out/<имя репозитория>/`.

Пользователю агент отдаёт числа только из `report.summary.json` (здоровье, находки, доли
компонентов, покрытие токенами, топ-5 проблем — см. [project-report.md](project-report.md#summary))
и кликабельную ссылку `[Открыть дашборд](file://…/report.html)`.

## Токен

Навыки Pixso никогда не читают `.env` и не спрашивают токен в чате. Если команда вернула код 3
(нет токена или он отклонён), агент передаёт строку fguard дословно — в ней готовая команда
`fguard token <ваш токен>` и путь к файлу, — просит выполнить её в своём терминале и после ответа
повторяет шаг один раз. Подробнее — [token.md](token.md).

## Удаление

`bash install --uninstall` удаляет ровно эти три папки; остальные навыки в `skills/` остаются.
Если папку навыка удалили вручную, следующий `bash install` вернёт её.
