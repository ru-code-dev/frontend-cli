07 PASS tty · ru · ok — fg --help --preport
$ fg --help --preport
fg --preport <путь|repo> [-o <путь>] [--format …] [--ui-kit …] [--config …]
  также: --project-report

  Отчёт по фронтенд-проекту: доступность, компоненты, иконки, дизайн-система. Код возврата: 0 —
  ошибок нет; 1 — есть ошибки (с учётом конфига) или сбой; 2 — неверный вызов.

  <путь|repo>                       Каталог проекта на диске или ссылка на репозиторий (http(s)://…,
                                    git@…, file://…) — он будет клонирован во временный каталог и
                                    удалён после анализа
  -o <путь>                         Куда записать отчёт: ФАЙЛ, когда формат-файл один, и КАТАЛОГ,
                                    когда их несколько (внутри — report.<ext>). Необязателен: без
                                    него — ./fg-out/report.<ext>; недостающие каталоги будут созданы
  --format html|compact|json|sarif  Что произвести: html, compact, json, sarif — несколько через
                                    запятую, порядок не важен, повторы игнорируются (по умолчанию
                                    html). html — самодостаточный HTML-отчёт; compact — находки в
                                    консоль; json — массив в формате ESLint; sarif — SARIF 2.1.0 для
                                    IDE и CI
  --ui-kit eds|eds2|none            Какую дизайн-систему учитывать: eds, eds2, none. Без флага она
                                    определяется по зависимостям проекта; если ничего не подошло —
                                    проверяются только общие правила
  --config <файл>                   Путь к файлу конфигурации правил (fg.config.json). Без флага он
                                    ищется сначала в корне анализируемого проекта, затем в текущем
                                    каталоге; если нигде нет — работают значения по умолчанию

  Примеры
    fg --preport . --format compact
    fg --preport ../app --format html,sarif -o ./out
08 PASS tty · en · ok — fg --lang en --help --preport
$ fg --lang en --help --preport
fg --preport <path|repo> [-o <path>] [--format …] [--ui-kit …] [--config …]
  also: --project-report

  A front-end project report: accessibility, components, icons, design system. Exit code: 0 — no
  errors; 1 — errors (after the config) or a failure; 2 — a wrong invocation.

  <path|repo>                       A project directory on disk, or a repository link (http(s)://…,
                                    git@…, file://…) — it is cloned into a temporary directory and
                                    removed after the analysis
  -o <path>                         Where to write the report: a FILE when exactly one file format
                                    was asked for, a DIRECTORY when several (report.<ext> inside
                                    it). Optional: without it, ./fg-out/report.<ext>; missing
                                    directories are created
  --format html|compact|json|sarif  What to produce: html, compact, json, sarif — several
                                    comma-separated, order irrelevant, duplicates ignored (default
                                    html). html — a self-contained HTML report; compact — the
                                    findings in the console; json — an ESLint-shaped array; sarif —
                                    SARIF 2.1.0 for an IDE or CI
  --ui-kit eds|eds2|none            Which design system to measure against: eds, eds2, none. Without
                                    the flag it is detected from the project's dependencies; when
                                    nothing matches, only the generic rules are checked
  --config <file>                   Path to the rule configuration file (fg.config.json). Without
                                    the flag it is looked for in the analysed project's root first,
                                    then in the current directory; when neither has one, the
                                    built-in defaults apply

  Examples
    fg --preport . --format compact
    fg --preport ../app --format html,sarif -o ./out
